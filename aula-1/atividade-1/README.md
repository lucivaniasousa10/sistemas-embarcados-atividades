## Componentes utilizados

- Arduino Uno
  -  Arduino Uno
-  Protoboard
-  LED vermelho
- LED amarelo
-  LED verde
-  resistores
-  botão (Pushbutton)
- Fios jumper para conexões


## Como funciona

O Arduino Uno controla os três LEDs conectados à protoboard.
O botão é utilizado como entrada do sistema. Quando pressionado, envia um sinal ao Arduino, que pode identificar o acionamento e realizar as alterações nos LEDs conforme a programação.

## Testes realizados

1. Testes dos LED,S,verificar se os três LEDs acendem corretamente.
2. Testes dos botoes,verificar se o Arduino identifica quando o botão é pressionado.
3. Testes do funcionamentos,verificar se os LEDs respondem aos comandos programados no Arduino.
